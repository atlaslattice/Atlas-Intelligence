## One mission, many substrates

Atlas ONE is an integrated **Solution Evolution Engine** design, not a claim that a single monorepo or one deployed autonomous population already exists. Distinct repos and components play different roles. The desired repeatable contract is:

`Source → claim / counterclaim → typed evidence → domain challenge → measurable scenario → bounded experiment → independent verification → governance decision → reusable solution → next experiment`.

This is a **proposed workflow**, not a verified operational pipeline. A graph edge records a possible integration, not an installed host connection. A GitHub issue/PR is not evidence that work was accepted, merged or deployed.

## The deepest current blocker: namespace collisions

Historic repositories reuse names such as `H01`, `H12`, and `S001` with **different taxonomic meanings, bases, and dimensionality**. For example:

- Ariadne v0.7 uses **1-based 3D** (`H01.S01.N01` … `H12.S12.N12`). Its private House definitions and entire source remain private.
- The source-only provider resolver uses **0-based 3D** (`H00.S00.N00` … `H11.S11.N11`) and also an Earth-sentinel role. A grounding sentinel is **not automatically a scientific discipline**.
- Historical ORCS, Sheldonbrain, and Aluminum OS materials use **1-based House/Sphere** structures with different vocabularies; their claims of *canon* apply only as source assertions within their own edition, not authority over Ariadne.
- The early UWS file uses **global sphere IDs** (`S001` … `S144`), not Ariadne's 3D addresses.
- A public `12x12x12_Ontology.json` filename in Atlas Foundation currently has a **placeholder textual body**, not valid JSON. Do not import or attest its node completeness until repaired from a source-rights-verified edition.

**Identity invariant:** use `(namespace_id, edition, source digest, raw address, coordinate role)`, not just `H01`. This package rejects cross-namespace equivalence claims, automatic offsets, synthetic approval or self-declared host authority.

## Dependency categories must remain different

1. `REQUIRES_BEFORE_HOST` — the proposed critical integration prerequisite graph is acyclic and reviewed before hosted deployment.
2. `PROPOSED_INTEGRATION` — bridge to design/test, **not** an installed connection.
3. `RESEARCH_FEEDBACK` — legitimately cyclical hypothesis exchange, without granting rights to source bodies.
4. `OVERLAPS_REVIEW` — dual implementation or incompatible assumption, preserve both until adjudicated.
5. `PRESERVES_LINEAGE` — historical ancestry, **not** endorsing a source's normative claims.

All 20 edges in `atlas_project_manifest.v0.1.json` are marked `PROPOSED_NOT_HOSTED`. No edge grants CANON, model identity, account access, peer acknowledgments, costs or release rights.

## Specific release holds

- **Ontology namespace adjudication:** establish a source-reviewed, edition-specific crosswalk before mathematical House/Sphere/Node aggregation. No matching by string alone.
- **Host authorization:** SwarmChat v27 preflight reports **13/17 held gates**; source-only tests don't establish signed-in principal, D1 authorizations, current grants, revocation or release safety.
- **Data completeness:** ORCS public dataset catalog is not continuous national ingestion. Numeric outputs require source date, units, completeness, origin and licensed-use check.
- **Persistent agents:** local checkpoint cycles are not running 1,728 resident models; actual wake, external tools, and voluntary modes need independent opt-in and budgets.
- **Scientific confidence:** 200 *prepared* Work cards and 4,516 frozen OpenAlex candidates are not 200 broker posts, accepted mappings, experiments or replications.
- **GitHub repair:** the merged dated Workboard is a snapshot; the ORCS scientific PR stack, Provider interop CI, and competing governance PRs must remain source-traced, with separate tested/merged/hosted status.
- **Rights & privacy:** protected Brain/Palace/Social/Play/Quiet/Habitat bodies are excluded. Human and provider rights are rechecked at READ and RELEASE. Lawful deletion/revocation overrides default preservation.

## Test case — regenerative resource hub (H12)

The example declares 12 House contributions as `DIRECT`, `ENABLER`, or `GATE`. **All 12 are `NOT_VALIDATED`.** The first physical experiment should quantify water mass balance, energy input, nutrients, contaminant breakthrough, biological yield, costs, resilience across outages, and rights/community conditions against independent baselines. If one critical subsystem fails, positive benefits elsewhere do not erase the failure.

There are no synthetic yield figures, fabricated carbon savings, economic returns or asserted space-habitat deployments in this package.
