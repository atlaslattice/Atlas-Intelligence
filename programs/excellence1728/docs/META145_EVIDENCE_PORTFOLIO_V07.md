# META145 evidence portfolio v0.7 — typed, untrusted review envelope

**Purpose.** A small original Atlas-native, read-only companion to existing PR45/Atlas ONE and SwarmChat Work. It takes exactly 1,728 source-defined HSN node metadata records and 1,728 proposed review records, rejects structural and epoch violations, and produces 144 Sphere, 12 House and one META145 review summaries. It contains no Work publisher, issuer, broker, live OpenAI agents, storage credentials, scientific crosswalk ratification or automatic code execution.

**New useful behavior.** Coordinate-bound review tickets include source registry digest, original node record digest, output digest, exact dependency digest and permission revision. A borrowed ticket, stale output, changed source record, rights epoch drift, getter/accessor, sparse array, inherited data or hidden side property cannot be counted as a pass. This is not a cryptographic *attestation*; a caller able to fabricate data can compute hashes. The module only normalizes and checks consistency before host-backed verification.

**Status meanings.** PASS and FAIL are external reports with evidence digests, not independently authenticated judgments; HOLD and UNREVIEWED require no evidence digest and never count as completion; N_A requires a constrained reason. Every final report is `SOURCE_ONLY_REPORT_NOT_HOST_ATTESTATION`. A full 1,728/1,728 reported PASS still returns `REPORTED_PASS_NOT_ATTESTED`, never `PRODUCTION_APPROVED`, `CANON`, or `SAME_AS`. Any FAIL takes priority over HOLD; a missing node returns constant `HOLD` without row content. No cross-mode source material is permitted.

**Exact-source private replay.** The owner-private v0.7 companion loaded the original `ariadne_v07_original.json` (2,187,541 bytes, SHA256 `07533cf7a6b6f567259962bf73efee9b22b47cbacb429499787800e07864e5a6`), bound it to the local synthetic review-budget v0.7 output SHA and generated a full 1,728/144/12 portfolio with 1,728 `UNREVIEWED`. This test proves internal consistency of raw source identities, not actual Work permissions or merit.

**Reproduction, no credentials:** `node --test programs/excellence1728/integrations/test/meta145-evidence-portfolio.test.mjs` (19 focused cases). This test also runs in pure Node `--jitless`. The existing PR45 HTTP tests are separate; Node `--jitless` on those remains a negative environment result.

**Research lessons adopted without copying upstream code.** OpenAI Agents SDK suggests owned tools, guardrails and explicit handoff boundaries; SWE-bench emphasizes exact-source patches, isolated evaluation and distinguishing harness infrastructure failures from patch failures. No upstream source code was imported. Future OpenHands/Tree-sitter/ast-grep/Aider/pytest adoption requires pinned upstream versions and full dependency license review.
