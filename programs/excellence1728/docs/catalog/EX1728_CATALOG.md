# EX1728 — source-defined engineering catalog

**Status: PLANNED.** The catalog contains 144 individually authored engineering capabilities and 12 implementation phases per capability, yielding exactly **1,728 planned task contracts**. Generating these records does not implement the capabilities, complete the tasks, demonstrate performance gains, create agents, or execute resident Macroturns.

## Coordinate model

`EX.Wxx.Cxx.Pxx` is an engineering work address. Its workstream, capability and phase are independent of original Ariadne House, Sphere and node coordinates. The shared dimensions are organizational choices. They establish no semantic identity, equivalence, or ownership of a knowledge domain.

All 144 original Ariadne Spheres may review the entire engineering program through source-bound perspective packets. Those packets retain the complete 1,728-node source coverage and the original Ariadne digest `07533cf7a6b6f567259962bf73efee9b22b47cbacb429499787800e07864e5a6`. The catalog does not assign the first engineering workstream to the first Ariadne House or the first capability to the first Sphere. Original source labels and definitions are separate owner-provided inputs; they are not copied into the public engineering catalog.

The legacy Providers resolver uses a separate zero-based convention. Its source is explicitly inventoried, and the coordinate admission and namespace tasks require it to remain distinguished from the original Ariadne `H01..H12` convention and any administrative origin coordinate.

## What each capability records

Each capability supplies a substantive objective, inspected source targets and symbols, proposed acceptance-file paths, input and output contracts, positive acceptance conditions, negative cases, a losing case, measurable quantities, explicit prerequisites and shared write resources. Verified source targets are existing files whose bytes and named declarations were inspected. Proposed acceptance files are absent from those source snapshots and are labeled `proposed_file`.

Existing source behavior may already satisfy some objectives. Phase P04 can finish through evidence-backed `NO_CHANGE_REQUIRED` or `VERIFIED_REUSE`; a rewrite is not mandatory. Phase P06 may retain the baseline when an optimization loses or offers no demonstrated benefit. Neither outcome receives a fabricated gain. Capability metrics are measurement obligations, not reported results.
