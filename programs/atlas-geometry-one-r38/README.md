## What this actually builds

One coherent **12×12×12 source-addressed substrate** from the first source line,
using a single host-injected activation per request and twelve typed projection
interfaces rather than twelve competing retrievers or workers. The 1,728 HSN
addresses, 144 Spheres, 12 Houses and read-only META145 are original Ariadne
identities/perspectives—not newly authenticated semantic experts.

- Pure reversible coordinates and 9-token symbolic glyph representation.
- 12-neighbor cuboctahedral numerical routing, equal-degree shuffled control,
  *bit-identical flat default* when alpha=0, stable House/Sphere normalization,
  and exclusive four-band hierarchy.
- Source/purpose/tenant/model/rights-epoch contracts for **WORK** only, with
  explicit READ, INFERENCE_USE, RETURN and optional DISCLOSURE_RETURN.
- One result frame projected to Ariadne, neural head, Geometree, Graph Fabric,
  META145, glyph, AtlasGPT, SwarmChat Work, WorkLearning, evidence memory,
  research and governance ports.
- Typed, source-qualified graph relationships stay **UNREVIEWED**; memory
  receipts are metadata-only and not resident memories or training labels.
- A voluntary **50-slot** collaboration proposal (10 phases × 5 independent
  workstreams), not 50 fabricated turns, an additional scheduler or an invitation
  with automatic notification/consent.
- Static self-contained, mobile-friendly 12×12×12 inspection UI.

**This is a complete source-only *architecture reference*, not a complete
deployment of every project.** External provider/model, host IAM, Workboard
evidence, source bytes, network egress, resident communication and private
content remain with existing authorized owners. The host adapter is not bound.

## Inspect without installing or accessing a private corpus

```bash
cd programs/atlas-geometry-one-r38
node examples/inspect.mjs
# For later comparison, when the owner chooses:
npm run test:later
```

The example issues one **synthetic** 1,728-score vector; no source body, model
weight, human label, external request or resident turn is supplied. Its fake
rights callback is not real authorization. `web/inspector.html` is a local,
self-contained visual navigator; it does not call a backend.
