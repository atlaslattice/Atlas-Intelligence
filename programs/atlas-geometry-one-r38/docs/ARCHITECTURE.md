## Numerical definitions

Source axis address: `i=144(h-1)+12(s-1)+(n-1)`, h/s/n in 1..12.

Each axis uses the 12 vertices `(x,y,z) in {-1,0,1}³` with
`|x|+|y|+|z|=2`. Edges join squared-distance-2 vertices: four neighbors
per axis, twelve total per HSN. Equal-degree coordinate permutations provide a
matched structural negative control.

`flat = issued_scores` when alpha=0 (no added transformation).
`geometric=(1-alpha)*flat+alpha*mean(neighbor_scores)` is explicitly
a *different* ranking hypothesis, never an assumed performance improvement.
House/Sphere summaries use a stable global-maximum normalization across all
1,728 logits. They are not confidence in a claim's scientific truth.
Exclusive structural bands are self / same Sphere / same House / other House;
these bins are disjoint and computed by stable log-mass.

Source roles are **not** accepted by the numerical position. Historical
placement differentiates 1,008 domain and 720 method nodes; actual
domain/epistemic meanings must be verified from the original pinned registry.
A method relationship needs its subject. Cross-edition systems remain
`(namespace,edition,sourceDigest,originalAddress)` plus typed reviewed edges.

## Evidence before release

All candidate relationships carry exact source version and hash; neither
shared glyph, theme nor HSN index establishes semantic identity. The host
must supply a current authorized source and model result, and independently
pinned required negative evidence. Metadata review cannot grant actual
disclosure. READ, INFERENCE_USE, RETURN, and DISCLOSURE_RETURN are distinct.
Work stays separate from Play/Social/Imagine/Dream/Quiet/Brain/Palace.
