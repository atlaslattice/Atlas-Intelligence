## One neural computation, distinct function roles

- **Numerical layer:** one 384D pretrained embedding space and 1,728 addressed logits; optional local routing/training candidate.
- **Reference layer:** source family/revision/digest/HSN and typed edges. No embedding grants evidence or rights.
- **Application ports:** separate tools are consumers/services, *not* a second model, another retriever or learned neurons.
- **Authority layer:** existing host inference-use, disclosure-return, model/data training-use, expiry and constitutional controls. Never encoded as soft penalties.
- **Control readout:** E145 describes 12 House mass/means; never latent neuron 1729.
