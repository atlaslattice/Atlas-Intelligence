## Source and rights

The independent `sourcePort` callback is called at READ, INFERENCE_USE, optionally DISCLOSURE_RETURN, and RETURN. Any change in pointer generation, source catalog/history digest, model/head, rights epoch, issuer or required-set fingerprint HOLDS. The callback is *not authenticated by this library*; its synthetic replies are tests, not real source-use or byte-egress rights. The final host must independently bind request/tenant/principal, close the complete necessary evidence set, and atomically fence output bytes after the last check.

The 1728-score buffer is already issued by an existing encoder/head; Ω6 never computes a new head, never updates weights, never creates an ongoing scheduler.
