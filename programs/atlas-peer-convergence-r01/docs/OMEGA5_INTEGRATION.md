# Atlas Ω5 — Integrated source-bound peer review

**Status:** Local source-level engineering candidate, not a hosted, neural-quality, source-rights, training, scientific or CANON acceptance.

## What it actually connects

The existing Atlas ONE **single issued frame** is inspected by THREE existing, independently authored functions, not by another retriever, model or authentication service:

1. **PR70** `inspectConvergence()` — original source-traced HSN/top-k review and PR65/66 *metadata* consistency; peer rank/closure evaluators in the local fixture are mocks, not independent policy trust.
2. **PR71** `inspectIssuedYijing()` — full 1,728-score frame, source/edition/rights-epoch claims, and two intentionally different edition-tagged symbolic views. Only `cupwake-x4/v1` is used as this composition's default symbolic display; HSN remains the sole primary identity.
3. **PR69** `prepareOmega4PeerReview()` — bounded source-linked peer alternatives and unresolved dissent, without any model or protected source-body transfer.
4. **NEW Ω5** `composeOmega5()` — detaches data safely, binds all three reviews, separately verifies full binary64 score-frame bytes (including the sign of zero), and returns strictly non-promoting review metadata.

There are **zero new model requests** and **zero live host calls** within this module. This is not an external authorization assertion. A caller supplying all apparently matching pins proves consistency, **not provenance or rights**.

## Specific negative controls

- Hidden-score drift where the top-12 IDs and scores remain unchanged: `HOLD`.
- IEEE754 `+0.0` versus `-0.0` outside the visible hits: different full-frame SHA-256, despite identical JSON serialization.
- Signed-zero difference with properly replaced binary digest: **review-only** if all other claims match. No false physical/quality claims.
- Changed rights epoch, evidence-source hash, registry hash, required-set digest, principal/source edition or PR70 rank: `HOLD`.
- Open peer objection survives in `LOCAL_REVIEW_WITH_UNRESOLVED_OBJECTIONS`.
- Proxy/accessor, unsafe extra fields, bad scores and duplicate HSN IDs: `HOLD` with no injected getter execution.
- 144 scoped synthetic Sphere frames tested; does not equal 144 semantic changes.

## Unresolved gates, deliberately preserved

- Exact current host issuer and independently pinned READ / INFERENCE_USE / DISCLOSURE / RETURN rights.
- Source-dependent required-evidence completeness and negative/dissent closure; PR65 is a **review-only consistency utility**, not a grant.
- Atomic final egress and revocation between preparation and the first external byte.
- User-owned selected0.3 actual encoder/head replay, fresh human-reviewed held-out quality, paired cost/latency and real host source snapshots.
- GitHub Actions runner admission and hosted tests; zero-step failures are not test passes.
