## Open-source interoperability / rights

Official OpenAI Agents SDK JavaScript docs describe agents-as-tools, handoffs, input/output guardrails, tracing and approval gates: https://openai.github.io/openai-agents-js/guides/agents/ . This package does **not** install or invoke the SDK. A future authorized host may pass a typed question to pre-existing AtlasGPT tool ports.

Microsoft GraphRAG and LangGraph are **design-reference candidates**, not dependencies or transplanted implementations. Before adopting specific source functions, verify each upstream license, version, vulnerabilities, caller scopes and the existing Atlas source history; preserve upstream attribution and avoid incompatible rewrites. No upstream source is copied into the new C++/Python/JS engines.

## Measurable acceptance

Each proposed action must include `source edition+digest`, existing integration target, new code diff, negative falsifier, test command+exit status, compare-to-baseline, current READ+RETURN, independent reviewer, and release/rollback receipt. All user-private source remains local. A prepared command is not a posted message, a license grant, a model evaluation or a merged PR.
