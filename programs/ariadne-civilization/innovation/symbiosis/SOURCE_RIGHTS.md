# Source, permissions and novelty limits

- The previous 20 invention source operators and this extension fabric are original user-owned Atlas software in the existing Atlas Intelligence repository. This artifact is intended to be grafted beneath the existing repository LICENSE, retaining attribution and history.
- `private-source/source-index.csv` is an owner-authorized **derived Ariadne v0.7 index** and is present only in this owner-private reproducibility ZIP. Exact original `atlas.json` bytes are NOT bundled; this package cannot independently establish their host provenance.
- No external OpenManus, Eigent, GrokSeek, Qwen, DeepSeek or OpenAI SDK source is copied or redistributed here. Compatibility proposals are source-only typed interface descriptions; external licensing and security reviews are not thereby completed.
- In Play/Imagine/Quiet all fictional text is generated from this public prototype's operator names. The app has no network, storage, API keys, telemetry, source ingestion or resident authentication.
- All 420 extensions are **directed compositions of 20 underlying tested operators**. The directed pairing configurations and their software scaffolding are concrete, but global novelty, research correctness, human/agent identity, accuracy gains, real-world civilizational benefit, or deployed functionality have NOT been established.
- A caller-provided hash or self-reported authorization flag is not a publisher signature or host principal. Host rights must be enforced by the existing trusted environment at admission, READ, RETURN and any controlled egress.
- Owner-wide enthusiasm for exploration does not authorize releasing protected data, spending funds, mutating private CANON/Brain/Palace, calling paid models, or merging unreviewed public code.
