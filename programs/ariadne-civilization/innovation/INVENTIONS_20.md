# Twenty proposed Ariadne / META145 enhancements — executable hypothesis cards

**Status:** 20 original source-only code experiments authored in this sprint, **not** verified world-first inventions or completed hosted improvements. These proposals are distinct from the existing source-pinning, current-rights and META145 hierarchy mechanisms; full repository and academic prior-art review remains open.

Each experiment is an independent deterministic function exported from `src/innovations.mjs`. Its unique ID is `I01`–`I20`, **not** an Ariadne HSN coordinate, EX engineering task, genuine AI agent or license to run a real source query. `src/compositor.mjs` combines the functions in an advisory candidate, not a semantic decision. The source-index sweep uses a trusted derived Ariadne v0.7 CSV; the full original private atlas.json is not bundled.

The strongest intended novelty is **the composition** of cross-House missing-evidence exploration, disagreement conservation, methodological challenge, reversibility and fair unknown-reduction in one existing Atlas-compatible source fabric. Individual algorithms (BFS, set cover, Pareto, leave-one-out) are established methods, not patented or globally new mathematical discoveries. Independent baseline research and user studies would be required before claims about breakthrough performance.

## Acceptance gates for every candidate

1. Reconcile source claims against current Ariadne edition and source hash; carry complete existing source history; do not auto-promote fuzzy OpenAlex links.
2. Independently reproduce at least one success and one falsifier in the existing Atlas ONE/native-v2 runtime and in a held-out public Work problem.
3. Compare to a **same-evidence, same-rights baseline**; report null results, regressions, cold-start costs, uncertainty and group-specific effects.
4. Bind any Work data to current host principal and source-specific READ/RETURN rights; never use the `LOCAL_SYNTHETIC_CANDIDATE` result as a trust credential.
5. Respect 12×12×12 source identities and protected modes; never derive a resident identity from a member display name or self-declared specialty.
6. For live functionality, integrate with the CURRENT existing Atlas Intelligence 2.0, native AtlasGPT and SwarmChat host surfaces, use staging, review, CI, rollback, test with two disposable principals and capture the served release SHA.

## Suggested compositional experiments (not yet run on real data)

- **I02 → I10 → I20:** compute missing knowledge obligations; prioritize orphan Nodes; offer diverse voluntary review choices subject to evidence and rights.
- **I03 → I05 → I11:** find source-family repeats, preserve contested interpretations, generate falsifiable research controls.
- **I06 → I07 → I08 → I09:** propose cross-House bridges, guarantee a methodological lens, and quantify unreviewed crosswalk prerequisites.
- **I12 → I13 → I14 → I15:** examine synthetic decision fragility, hard constraints, minority objections and withdrawal robustness.
- **I16 → I17 → I18 → I19:** prepare reversible experiments, compact source citations, generate negative mutations and test cross-port serialization parity.

**Never collapse** these into one scalar 'civilizational IQ'. The candidate compositor preserves source/policy boundaries; any later composite output remains correctable, non-authoritative and evidence-linked.
