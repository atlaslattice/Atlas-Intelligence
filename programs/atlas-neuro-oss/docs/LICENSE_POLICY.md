# License/attribution policy

`data/source_registry.json` records upstream repository-level SPDX metadata observed 2026-11-24. It does **not** establish the license of each file, weights, model, data or downstream embedded third-party dependency. No upstream source bytes are copied in this package.

- Permissive root-license candidates: MIT, Apache-2.0, BSD-3-Clause, PostgreSQL, CC0-1.0. Reuse still requires file scope/NOTICE/attribution review and a recorded compatible provenance decision.
- Separate review holds: Norse (LGPL-3.0), BindsNET (AGPL-3.0), Tonic (GPL-3.0), Nengo (GPL-2.0), Brian2 (CeCILL 2.1), Lava (repository archived May 2026; license not classified from GitHub API).
- Cursor's own editor internals are not treated as open-source. We include public `.cursor/rules/*.mdc` and `AGENTS.md` conventions and refer to a CC0 community rule collection. These do not grant platform runtime permissions.
- A feature remains PREPARED_NOT_POSTED until the trusted host and current owner approve actual effects. No automatic code copy, merge, training or deployment.
