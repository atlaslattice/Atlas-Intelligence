# Additive Atlas native engineering architecture (public-safe)

Twelve engineering modules, each 12 proposed features; one source-bound review workboard. Each module contract is JSON, carries source URLs and a disproof test, and has **zero** installed functions. The separate native reference library actually implements a small set of pure testable utilities. The released Atlas pretrained retriever/Work Learning runtime is not modified.

1. Source and eligibility manifest
2. Neural embedding and retrieval experiments
3. Typed Graph learning and explicit candidate edges
4. Matched-capacity neural adaptation research
5. Separate spiking/neuromorphic CPU oracle
6. Temporal memory and source-revision replay
7. Training/curriculum under dataset rights
8. Independent family-disjoint evaluation
9. Optional storage and serving benchmarks
10. Host rights and original source integrity
11. Glyph, META145 and accessible navigation
12. Cursor/AGENTS/OpenAI optional interoperability

Unresolved boundaries: actual source licenses and rights, honest gap assessment, full eligible corpus, human-reviewed science, real host inference-use and return authority, MICA/Omega ABI integration, production training, hardware measurements, hosted deployment and CANON. These are intentionally not treated as completed.
