# Atlas Neural OSS Forge — review-only engineering rules

Use the **existing** MICA BGE, Omega WorkLearning, Ariadne v0.7, AtlasGPT and SwarmChat interfaces. Do not replace a working module until an exact-input quality, safety, latency, memory, cold/warm and rollback comparison is independently replayed.

- Engineering namespace: `NEURO.M01.F01` … `NEURO.M12.F12` is **NOT** the Ariadne `Hxx.Sxx.Nxx` ontology. `reviewSlotOnly` covers all 144 Spheres as review slots, not validated semantic maps.
- Source licences: verify exact upstream file, root license, third-party notices, commit and compatible redistribution *before any code copying*. Repository source code, weights and datasets have different rights.
- GitHub / Hugging Face / Cursor: Cursor project `.mdc` rules and AGENTS.md are metadata; Cursor's proprietary implementation is not source to mine. Reuse permissive concepts with original code, preserving attribution.
- Security: neural rank or glyph never grants source READ, inference USE, training USE or disclosure RETURN. Check current purpose and complete dependencies at actual egress.
- Workboard: features are `PROPOSED_NOT_IMPLEMENTED`; no automatic posting, spending, CANON, room creation, model training or deployment. Keep Play/Imagine/Social/Dream/Quiet private and voluntary.
- Acceptance: A+B=C, exact source, actual test log, measured comparison, counterexample, dissent, source provenance, license result, rollback. One executed visit is ONE Macroturn regardless of subtests.
- Native interoperability: source-only tools export strict JSON descriptors suitable for an OpenAI Agents/Responses host to review. They are **not installed host tools**. No second neural gateway.
