**Review-only draft.** 57 curated repository metadata records, 144 source-linked feature proposals across 12 engineering modules, 12 module contracts, and tested original dependency-free reference functions. No third-party neural source files copied, no model weight/data access, no training, no hosted neural service and no CANON authority.

The 144 cells `NEURO.M01.F01`–`NEURO.M12.F12` are **engineering slots**, deliberately distinct from immutable Ariadne `Hxx.Sxx.Nxx` source identities. `reviewSlotOnly=Hxx.Sxx` is a coverage prompt, NOT an approved semantic relation. No external network or package installation required. Tool descriptors in `src/native_core.mjs` are *compatible review proposals*, not installed OpenAI tools. No SwarmChat posts or background tasks are created.

## Reproducibility and boundaries

All original references are source-only and no-scored-native: `parseHSN` checks one-based 12³ identity grammar; `featureLibraryStatus` applies conservative warnings; `vectorCacheKey` and `evidenceBindingKey` distinguish model semantics from rights; `stableExactTopK` is an exact baseline; `lifStep`/`runEventLif` are discrete CPU simulation only; `familySplitPreview` and `reviewNeuralReferences` do not authenticate host grants; `generateWorkOrders` returns `PREPARED_NOT_POSTED`; `deterministicBuildOrder` is a review dependency DAG, not a neural knowledge graph. Retain all results/negative tests/unknowns. No use on a live unauthorized corpus.

The full workbook, owner-private exact MICA/Omega audit and private synthesis are delivered separately, not committed publicly.
