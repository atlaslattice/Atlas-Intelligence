**Three namespace rule:** Original Ariadne semantic Hxx.Sxx.Nxx IDs are NOT AOS.Wxx.Cxx.Pxx engineering work IDs or `atlas.os.spatial/v1` physical addresses. The 1,728 ordinal comparison in tests establishes structural parity only. Never infer same meaning, hardware resource, permission, or HSN source ownership from matching numbers. Original v0.7 is the source of IDs, parents, names and roles.

**CANON state:** Exact CANON 144 R13 is pinned as a reviewed candidate, NOT a ratified release or an active kernel permission policy. The synthetic R02 `r02_share` is an arithmetic unit and depends on already verified accounting, rights and scope; it cannot authorize scheduling, data transfer, training or Work. R13's R12-protected Quiet correction remains intact. The subsequent Boolean-vs-integer scope concern remains a known nonpromoting reference-code blocker; native OS R03 does not mint identity, scope or source decisions.

**Ownership/reuse:** Original R01 `atlas.c`, `atlas.h`, `selftest.c` and original R02 `native.c`, `native.h`, `boot.S`, `link.ld` are copied *byte identically* from the recovered owner-private archive. R03 changes the boot marker and adds new original source. Peer R02 Mission Control and Hearth remain alternative *consumer* integration candidates, never silently folded into the ring-0 core. R15 technical artifact was review-only and is not silently called a newer adopted constitution.

**Authority model (not implemented):** Kernel hardware authentication, an OS-owned monotonic clock and actual host credentials must be bound to all requests BEFORE actions. Current C functions accept injected caller IDs and synthetic time. A public HSN or printed checksum is not an authorization token. Protected mode/palace content never becomes mandatory Work data, and no automatic resident wake or private-data ingestion is permitted.

**Current review status:** R03 is compiled and locally tested but not booted, not remotely installed, not connected to current SwarmChat rights, not trained and not deployed. All full-OS functionality has explicit source and acceptance gates in `COMPLETE_COMPONENT_INTEGRATION_MATRIX.json` and the original 1,728-row R01 engineering register.
