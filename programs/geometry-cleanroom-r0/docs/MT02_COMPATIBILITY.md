## Mixed-radix editions

For each independent zero-based H/S/N axis `x=0..11`:

- **Cupwake R01:** `x=4*t+b+2*c`, `t=0,1,2`, `b,c=0,1`.
- **Geometry Symbiosis v0.3:** `x=3*(b+2*c)+t` with the *same* bit/ternary domains.

The three `b` bits form a lower trigram (0..7); three `c` bits form the upper trigram (0..7). The binary pattern code is `lower+8*upper` (0..63). The ternary context code is `t_H*9+t_S*3+t_N` (0..26). Encode+decode are bijections of the canonical 1,728 addresses **within each named edition**; the same numeric pattern/context is not edition-independent. Changing one of six bits is an involution; changing a context digit by ±1 is bounded (no wrap). There are 5,184 undirected symbolic bit-flip edges and 3,456 undirected adjacent-context edges.

## Cymatic glyph layer

It is **dimensionless** and is not a measured vibration, calibrated plate eigenfunction, frequency prescription, material map, or verified physical bridge. The existing owner Work explorer explicitly distinguishes its GF7 analytic plate reference from the symbolic glyph. **Do not infer an actual Hz value** from an HSN, hexagram or nine coefficients.
