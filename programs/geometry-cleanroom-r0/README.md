# Geometree R0 — an independent clean-sheet Atlas geometry kernel

**State:** `LOCAL_SYNTHETIC_REFERENCE_CANDIDATE` · **No production merge, host deployment, training, or automatic resident work.**

This is a complete *minimal vertical slice* from a host-injected canonical neural gateway boundary through geometry-native scoring, House/Sphere/Node reductions, source-use review, and four identical local consumer aliases. It is **not** a complete rewrite of every existing Atlas module or corpus. External model weights, provenance authorities and hosted delivery deliberately remain outside this candidate.

One source of ranking: the host-injected `gateway.request()` returns a preexisting *issued neural* 1,728-score result. This candidate performs no lexical retrieval, no second provider call and no independently trained expert invocation. The host-injected `policy` performs separate READ, USE, DISCLOSE where required, and RETURN checks. A host-injected `reviewClosure` supplies a required-evidence decision. Even with nominally allowed fixtures, the kernel returns `PREPARED_NOT_HOSTED` with `releaseAuthorized:false`, `trainingEligible:false` and `authorityEffect:'NONE'`.

## Reproduce

Requires **Node.js 22 or newer**, no npm packages, no network or credentials.

```sh
node --test test/kernel.test.mjs
node --jitless --test test/kernel.test.mjs
node src/benchmark.mjs
node scripts/generate_manifests.mjs
```

The test suite contains 144 sphere-path fixtures, 144 independent House-indexed malformed-result fixtures, and additional input validation, authority, math, and ablation tests. Every score is synthetic. The benchmark runs 48 seeded cases for each of four top-k values. Test successes are not scientific, model-quality, semantic, cultural or hosted-system acceptances.

## Files

- `src/geometry.mjs`: reversible Hxx.Sxx.Nxx addresses, typed crosswalks, exact sparse top-k and the flat baseline.
- `src/kernel.mjs`: clean-sheet single-result geometry core with source/permission checks, typed views and non-authoritative role metadata.
- `src/fused-online-control.mjs`: preserved losing C1 one-pass log-sum-exp efficiency candidate.
- `src/fused.mjs`: C2 second rewrite: two-pass stable normalization with fused heap selection and original House/Sphere aggregation.
- `src/benchmark.mjs`: synthetic, order-biased process-local comparison A versus B versus C1 versus C2.
- `test/kernel.test.mjs`: full fixtures and adversarial conditions.
- `manifests/addresses.json` (generated by `scripts/generate_manifests.mjs`): all 1,728 original HSN addresses with explicit `ADDRESS_ONLY_NOT_REVIEWED` status.
- `manifests/workboard_144.json`: 144 **proposed** review cells, not 144 completed implementations.
- `evidence/*.tap`, `evidence/benchmark.json`: test records and negative findings.
- `ARCHITECTURE.md`, `CHALLENGE.md`: architecture contract and voluntary peer design challenge.
