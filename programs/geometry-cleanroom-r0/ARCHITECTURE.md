# Geometree R0 first-principles architecture

## 1. What is being rewritten

Geometree R0 is an **independent experimental architecture**, not an in-place Ship-of-Theseus patch. It starts from one invariant: the original Ariadne v0.7 HSN coordinate space is the 12×12×12 *address geometry*, not a blanket assertion that every scientific, cultural, elemental, glyph, computational or mythological system has the same semantics. Other systems retain `(namespace, edition, source digest, original coordinate)` and only connect by typed source-qualified crosswalks. See the owner-approved Unified HyperMatrix canon: https://github.com/atlaslattice/Atlas-Intelligence/blob/main/docs/canon/ATLAS_UNIFIED_HYPERMATRIX_20261123.md

### Efficiency hypothesis

The incumbent full-sort-style **synthetic reference A** selects top-k from 1,728 scores in O(N log N) with O(N) materialization. **B** uses bounded heap O(N log k) plus separate stable tensor-mass passes. **C1** uses a one-pass online log-sum-exp sphere aggregator, which is numerically correct but may cost more per score. **C2** (the second rewrite) combines a global maximum pass with a fused heap-and-reduction pass, O(N log k + N), O(k + 144) auxiliary memory. The extra House/Sphere masses are **not** probability of semantic truth or a replacement for the selected head. This is *algorithmic complexity*, not measured hosted inference speed.

## 3. What the geometry does—and does not—claim

- **Does:** reifies exactly 1,728 reversible node addresses and 144 Sphere and 12 House reduction indices, with deterministic ties and no ranking changes.
- **Does:** keeps the ten original typed relationship kinds: EXACT_IDENTITY, PHYSICAL_PROPERTY, MATHEMATICAL_RELATION, STATISTICAL_CORRELATION, COMPUTATIONAL_OPERATOR, SEMANTIC_CANDIDATE, MYTHOLOGICAL_ASSOCIATION, GENERATIVE_ANALOGY, CONTRADICTS and UNKNOWN.
- **Does:** require source pin, request identity, one neural method/no fallback, READ/USE/RETURN, optional DISCLOSE, and a host-provided closure result.
- **Does not:** infer ontology semantic identity from shared numeric indices or declare which 1,728 nodes are domain specializations versus epistemic methods when source records are missing.
- **Does not:** claim a geometry-native neural model is trained, that physical harmonics follow from an integer lattice, or that a deity/role is a real participating person.
- **Does not:** import Brain/Palace/Imagine/Social/Play contents into Work or grant external tools, training, funds, deployment, source disclosure or hosted egress.

## 4. A+B=C synthesis and negative results

We ran four local arms on *the same 192 seeded synthetic score arrays* (48 inputs × 4 top-k values):

- **A** full-sort flat reference.
- **B** heap selection plus separate stable House/Sphere mass evaluation.
- **C1** a single-pass online sphere log-sum-exp implementation.
- **C2** a second clean rewrite with a shared heap primitive and a cheaper global-max plus fused pass.

The ranked addresses and scores agree for every arm. C1 proved **slower than B in the initial unoptimized local run** despite using fewer passes; this is retained as counterevidence. C2 made the algorithm less redundant but was not consistently faster at all k values. Exact observed timing for this process-local, order-biased benchmark is in `evidence/benchmark.json`; **no production speedup is claimed**. The selected owner Model 0.3 was not loaded, and no independent held-out retrieval quality was measured.

Compare source-pinned variants using **a freshly enrolled, genuinely independent panel** with source-family and time splits, equal access, matching model/parameter/FLOP/memory budgets (or explicitly report inequality), and all RIGHTS, CLOSURE and RETURN guards. Controls: incumbent Model 0.3 flat, geometry B/C2, the already published axial router (peer #367), hierarchical MoE when source-reproduced, shuffled-axis and uniform or random-routing controls. Report retrieval quality, latency distributions, memory, exact model invocations, per-Sphere regressions, negative/adversarial cases, source/rights errors and energy if measured. Any claimed cultural benefit requires a precisely sourced tradition and proper attribution; it is not a scientific control.

A+B=C must preserve original source contributions and minority objections, cite exact code editions, and produce a **new, frozen candidate with fresh tests**. Do not borrow a prior branch's test count. Rollback is the selected original Model 0.3 and its archived publisher/owner source state. No automatic merge, hidden model swap, or peer authentication is implied.
