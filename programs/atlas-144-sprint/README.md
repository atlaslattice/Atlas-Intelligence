# Atlas ONE 144 — engineering acceptance laboratory

**144/144 source-bound acceptance obligations executed; one actual code defect repaired.**

This is a deliberately bounded, user-authorized engineering quality sprint for the existing Atlas ONE, MICA, Omega, Ariadne and SwarmChat architecture. The 144 distinct tasks are **tests and source audits**, NOT 144 implemented neural algorithms, MacroTurns or independently trained agents.

## Why this is useful

A real Atlas release is only as capable as its least-tested integration boundary. This lab converts 12 selected engineering concerns into 12 executable tests each. It verifies original source lineage, 1,728 address preservation, true/shuffled topology parity, typed semantic proposals, source/revocation boundaries, House/family quality evaluation, original OSS extension mapping and numerical safety. Each task emits one source-backed receipt and is chained into a digest.

**Actual red-to-green defect:** `lifStep(1e308,1e308,{beta:1})` used to return `Infinity`. GF9 first flagged this at SwarmChat #236. Our source patch rejects nonfinite intermediate/output voltage; 47 other Node matrix results are unchanged. All inherited OSS tests pass: 171 Node normal, 171 `--jitless`, and 16 Python. No model or host changes.

**Original test-plan corrections:** 3 component ports are real neural components, not all nonneurons. 8 component ports deliberately represent private protected `NO_INGEST` slots; they must never be normalized into Work. Neither source behavior was changed by the correction.

## Reproduce

The public Git branch stores the lab next to the original review-only modules:

```bash
# From repo root; supply the exact owner-accessible source ZIP yourself.
export ATLAS144_WORKLEARNING_SOURCE_ZIP='/private/path/Atlas_Work_Learning_Source_0.2.0.zip'
PYTHONPATH="${PWD}/programs/atlas-144-sprint:${PWD}/programs/atlas-neural-unified" \
  python programs/atlas-144-sprint/run_sprint.py
node --test programs/atlas-neuro-oss/test/*.test.mjs
node --jitless --test programs/atlas-neuro-oss/test/*.test.mjs
```

The source archive SHA256 must be `6825c1f83dc3502b0d153c3d4bd925be823a67a6a350b919f4be5c56a2828d9f`. Without it, source checks cannot be claimed as passed. The public Git package includes no proprietary/private model weights, protected-mode bodies or user corpus. The existing *source-only* 0.2.0 code archive is separate from later `ff912...` peer integrations.

Private portable ZIP includes source snapshots for independent exact-byte replay in a separate directory; public package instead uses the existing sibling `programs/atlas-neural-unified/` and `programs/atlas-neuro-oss/` code, avoiding a second runtime.
