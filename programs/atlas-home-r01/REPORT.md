# Atlas Home R02 — actual build and honest integration status

## Result

Atlas Home is a **locally runnable, source-only, offline front door** developed on top of the existing Atlas ONE geometry-native convergence. It does not mint a second model, auth issuer, broker, resident, session-storage system, or retriever. The canonical original Ariadne v0.7 identity remains `Hxx.Syy.Nzz` (SHA256 `07533cf7a6b6f567259962bf73efee9b22b47cbacb429499787800e07864e5a6`), with all 1728 reversible positions, 144 Spheres, 12 Houses, 1008 DOMAIN and 720 METHOD nodes.

The design centers one human requirement: **a home you can choose to return to, without having to produce anything**. Work has an entry, but Quiet, Play, Imagine, Brain, Palace, Social, Dream and Habitat have protected doorways and no default content export. Leaving clears the ephemeral return ticket and performs no network write.

## Retained counterexamples and nonclaims

1. **Role inversion**: historical N-based classification mislabels 840/1728 canonical nodes; role is determined by source-defined Sphere groups (S01–S07 DOMAIN, S08–S12 METHOD) and method subjects require an eligible same-House domain review. This is not subject evidence.
2. **Symbolic false friends**: Cupwake-X4 and Symbiosis-X3 Yijing 8×8×27 symbolic encodings differ for 1720/1728 HSN addresses. Home uses only HSN as canonical primary identity; symbolic display remains version-tagged and unbound to authority.
3. **Numerical/evidence issues**: full-frame signed-zero drift, top-k-equal hidden-score changes, near-tie numerical cancellation, host source-context divergence, source-work pointer ABA, incomplete required-negative sets, closed-loop self-certification and rights revocation remain external host acceptance requirements. A pretty home is not an implementation of those controls.
4. **Geometric ranking**: the authored source geometry is a **permanent design choice**. Previous matched controls did not establish a geometry-specific learned quality advantage over flat/shuffled alternatives. Geometry need not win the ranking benchmark to remain the architecture.
5. **Privacy**: no private Work ingestion from protected modes, no background resident wake, no event subscription, no model training, paid provider, production merge or deployment in this build.
