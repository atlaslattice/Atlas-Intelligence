# Open-source stewardship, not uncredited copying

Before any project becomes an Atlas-native maintained fork or a preinstalled app:

1. Preserve the ORIGINAL project author, repository, history, NOTICE, SPDX/copyright/license files, and original asset licenses. Prove exact commit/tag, release artifact digest and source correspondence. A webpage or star count is not a code audit.
2. Record separately: code license vs trademark/branding vs fonts/icons/photos/audio vs packages/data vs cloud service. Open-source code does NOT imply a legal right to ship another team's icons, logo, trade dress or name on a modified build.
3. Prefer upstream patches and standard data formats. If native rewrite is beneficial, document original attribution, independent implementation, interoperability test cases, compatibility specifications, any required clean-room boundaries and all known regressions. Claim neither endorsement nor affiliation with other brands.
4. Respect copyleft and notice obligations when distributing modified GPL/AGPL/MPL software. License compatibility is a review problem, not a flag a text model may simply set.
5. Keep migration reversible: dual-write only with permission, verify DOCX/ODS/XLSX/PDF/PSD/SVG/RAW/project fidelity with roundtrips and user's real samples, maintain backup copies and a downgrade path.
6. Stage unmaintained/alpha alternatives behind a preview label. Never remove a known working tool on the basis of a screenshot or a viral README.
7. Protect external users' accounts: a local biometric can unlock a device key, not sign into unrelated service domains without their OIDC/passkey flow. Hardware security and private data may only be accessed through their explicit current rights.

Every catalog source includes an official homepage and declared upstream repository. Every license claim is PENDING_EXACT_LICENSE_AND_ASSET_REVIEW, every exact upstream commit is null, and every live installation flag false. This is transparent source discovery, not finished source provenance.
