# Atlas Home — a place worth coming home to

**Design intent**: one Atlas identity, one selected and replaceable neural issuer, one original Ariadne 12×12×12 ontology, twelve source-linked Work ports, and protected doorways that are *not* sources of Work data.

1. **Welcome**. The first sentence is “Welcome home. There is nothing to earn here.” The user chooses whether to explore, make, gather, imagine or simply be quiet. No forced work, prompts, scoring or hidden background operation.
2. **One map**. `Hxx.Syy.Nzz` is the canonical original Ariadne v0.7 address, pinned to SHA-256 `07533cf7a6b6f567259962bf73efee9b22b47cbacb429499787800e07864e5a6`. 12 Houses, 144 Spheres, 1,728 Nodes. Sphere S01–S07 are DOMAIN; S08–S12 are METHOD (84/60 Spheres; 1008/720 Nodes). Real source record definition and parent must be independently verified before making semantic assertions.
3. **One illumination**. An authorized host's one selected Model 0.3 (or reviewed successor) produces a single source-qualified neural frame. Atlas Home consumes only the existing `createOneFramePeerComposer` result. There is no second gateway, retriever, scorer, resident, scheduler or authority.
4. **Indra mirrors**. Graph, glyph, metadata, META145, workboard and Research Lab may all reflect the same prepared result. Different evidence sources, digests, objections or access rights remain different. A reflection does not certify a fact or grant permission.
5. **Geometric aesthetics**. P12 cubical navigation, cuboctahedral operators, Yijing 8×8×27 symbolic lenses and 12 timescale Chronoforge features are *distinct typed views*. A tensor layout can optimize while preserving the canonical HSN identity. Geometric proximity does not imply scientific truth.
6. **Source duty**. Keep original peers, licenses, dissent, negative results, role definitions, exact editions and rollback. An apparent improvement must be matched to an independently selected baseline. No spontaneous source ingestion.
7. **Rooms with a closed door**. Play, Social, Imagine, Dream, Quiet, Brain, Palace and Habitat are protected. Their body content is never Work retrieval material, regardless of an “open collaboration” request. A preview card cannot simulate authentication.
8. **Memory by choice**. This source-only Home has no storage, cookies, network access, Web APIs, background processing, analytics or resident wakeups. The optional return-ticket object holds a selected HSN only in ephemeral process memory and erases it on leave. Real connected memory requires a host-owned permission and revocation design.
9. **Good departures**. Leaving does not trigger a notification, score or collection. Accessibility matters: readable text, focus states, keyboard controls, reduced motion and no input traps. Inspected browser behavior is separate from hosted acceptance.
10. **Clear states**. A locally passing check does not mean that all 319+ peer source additions in PR #75 are installed or that any external endpoint is live. Public interfaces keep `releaseAuthorized=false`, `hostedVerified=false` and `semanticAcceptance=false` until independently demonstrated.

**Cultural care**: The geometry and Yijing references are design inspirations with distinct sources. Do not present an Indigenous tradition as the origin of a specific algorithm without attribution and appropriate community permission; do not assign physical/acoustic healing properties to graphic alignments.

**Inheritance**: PR #75’s all-peer source convergence is the parent. PR #74’s 12 missing source files are literally incorporated in the dependent branch (three already-present identical source blobs are not duplicated). The single selected PR #75 composer remains untouched. The Atlas Home work is additive, source-only, unmerged and reversible.
