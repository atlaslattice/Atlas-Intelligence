# 1,728-node Measurement Protocol — No Unmeasured Wins

`METRIC.Hxx.Syy.Nzz` is a unique source-specific **metric slot**. It is not a promise of a positive effect. Its `family` specifies an objective observable property, and its numerator/denominator and improvement direction are recorded separately from the original Node's subject. Each Node has a minimum 30 matched held-out examples and three independent negative controls; statistical power requirements may require many more.

## Baseline rules

1. Preserve the original source edition, exact node/sphere names, runtime commit, source license and task population, plus a complete stable list of eval case IDs before coding.
2. Baseline against the **best existing indexed Atlas ONE/AtlasGPT/SwarmChat build**, not an obsolete linear reference. Record cold and warm performance, p50/p95, CPU/memory and byte/network cost on the same environment.
3. Hold-out data must not influence changes or selection; if it does, replace it with a fresh independent set. Pair baseline/candidate on exactly the same tasks, source and rights.
4. Score the correct property: retrieval quality, source accuracy, correct abstention, factual calibration, numerator/denominator completeness, security false allows, or objective UX task completion. Do not substitute number of messages, source count or benchmark milliseconds for human welfare.
5. A rights/privacy/cultural-consent failure cannot be offset by performance. A zero-leakage hard gate is separate from an aggregate metric.
6. Submit matched data to `metric_adjudication.paired_preview`. Its exact one-sided discordant-pair sign test is a *candidate statistical check*, not an expert, safety or host acceptance verdict. Both unlabelled/forged case sources and claimed credentials are out of scope.
7. Independent reviewers must inspect the baseline provenance, error cases, source exclusions, license, affected groups and behavior before declaring any metric earned.
8. Promote statuses only from **planned → implemented → local-tested → CI-passed → hosted-verified → independent gain adjudicated** with actual evidence; never from a synthetic checksum alone.
