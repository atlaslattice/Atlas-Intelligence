# One Codebase / Seven Existing Ports / Zero Competing Control Planes

The owner requested 1728 authentic HSN knowledge seeds → 144 source-specific Sphere plugins → 12 existing functional House modules → one cumulative Meta145 synthesis. This design explicitly **reuses** Atlas Intelligence 2.0/Atlas ONE v2 and does not claim installed site changes.

## Authoritative source order

1. Original Ariadne v0.7 registry (`SHA256 07533cf7...e5a6`) defines coordinate, House/Sphere/Node subject, description, includes/excludes, and source-record digest. This is a source fact, not a semantic review verdict.
2. Atlas ONE `CivilizationUnifiedBuild` PR #42 defines actual twelve `MODULES` and `evaluateModuleFunction` input/fixture gates. Those remain authoritative for the work candidate. Node and Sphere paths are **config/adapter extensions**, not duplicate `CivilizationUnifiedBuild` implementations.
3. `CivilizationWorkHostBridge` implements a *prepared source-pointer*, not host authentication. Do not feed caller-declared `hostAuthenticated` or `rightsEpoch` into authority decisions. Only the trusted publisher can check at READ and actual RETURN/egress.
4. `AriadneRegistry`/`prepareResearch` in AtlasGPT's source-indexed core creates falsifiable source hypotheses with no model retraining. Preserve original source-version pins and never equate OpenAlex T-ID or glyph coordinates to HSN without review.
5. SwarmChat Work broker is a peer-evidence delivery/reference UI. Use existing rooms, permissions, event budgets, subscriptions and idempotency. Prevent protected creative/private-source harvesting.
6. Alexandria is a separate rights-governed archive, not a universal public source store. Only reviewed public-safe source code/tests go to Git.
7. Existing Atlas ONE Librarian D1 is the metadata acquisition queue; `ATLAS-EXCELLENCE-1728` is a *distinct* planned program of `EX.W.C.P` work orders, not a renamed 1,728-node knowledge map.

## Storage and read interfaces

- `NODE_SEEDS_1728.jsonl`: immutable source-qualified candidate tasks, one per HSN.
- `METRICS_1728.jsonl`: pre-registered metric definitions. Baselines and candidates NULL until real evaluation.
- `SPHERE_PATHWAYS_144.jsonl`: specific domain or epistemic-method adapter plus source requirements.
- `HOUSE_MODULES_12.json`: existing functional module identifiers. The source-only compiler does not write into D1.
- `MANIFEST_SHA256.json`: local integrity, not authoritative host signature or proof against deliberate rollback.
- Optional future D1 integration: a **single** publisher-owned host adapter reading these manifests under existing rights, with idempotent task identifiers, source pin invalidation, and hard gates.

## Failure-oriented acceptance tests

- Unknown/stale `Hxx.Sxx.Nxx` or forged source digest ⇒ HOLD.
- `H00.S00.N00`, `E145`, `EX.Wxx.Cyy.Pzz` or `GF7` string in HSN slot ⇒ HOLD.
- Epistemic-method node without an explicitly selected domain subject ⇒ HOLD.
- An OpenAlex topic candidate or Wikidata record without semantic review ⇒ CANDIDATE only; never SAME_AS.
- Late source epoch/permission revocation ⇒ no protected **body, count, label, summary, glyph, export or clipboard**.
- Unapproved private mode ⇒ no read, no telemetry, no Work processing.
- Social/Imagine/Dream/Play/Quiet scenes cannot be harvested into work datasets.
- Cold-cache cost and code-version change invalidate claims of warm speed gain; compare current already-indexed Atlas baseline.

## Host integration prerequisites

Source validation, file boundary, D1 schema migration preview, protected data survey, publisher identity, signed-in two-account revocation tests, CI/runner evidence, exact served HEAD, mobile/offline regression, ethical-source review and reversible rollback plan. **Do not merge or deploy from a roadmap generator.**
