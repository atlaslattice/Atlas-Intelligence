## What the additive adapter does

`atlas-cascade12-bridge.mjs` accepts a **privately prepared, sanitized, source-pinned metadata envelope** and produces a data-only `LOCAL_CIVILIZATION_REVIEW` task compatible in shape with the existing Atlas ONE `prepareLocalWorkBurst` contract (which already limits each local wave to 96 tasks and 12 concurrent operations). This adapter **does not call** Work Burst, send a SwarmChat message, open a room, dispatch a model, read private texts, grant identities, run a real broker, or modify any Site/host settings.

It refuses malformed/unverified exact source pins, mode ambiguity, old H00 coordinates, wrong sphere role, spoofed host verification, and all Play/Social/Imagine/Dream/Quiet suggestions. An eligible Work candidate remains *PREPARED_FOR_EXISTING_LOCAL_WORK_BURST* with **`canDispatch:false`**, not a permission grant. Independent user/current-rights and source checks are mandatory before any actual Work review; no implicit consent follows from a local hash.
