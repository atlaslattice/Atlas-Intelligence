- **Symbiosis proposer** (`src/node-symbiosis.mjs`): surveys the entire **12×12×12 = 1,728-node** lattice on each of 1,100 local iterations. It preserves **7 domain locators + 5 epistemic-method roles per sphere** (1,008/720). No proposition is semantic `SAME_AS`, knowledge consensus, earned merit, scientific calibration, or an authority grant. HSN names are just synthetic structural locators.
- **Constructively adversarial checker** (`src/node-adversary.mjs`): first intentionally corrupts a proposed relationship to `SAME_AS`; requires rejection before restoring the reviewable proposal. It then executes **27 independent local controls per node**: one inert positive, 24 adversarial privacy/identity/source/rights/replay/equivalence attacks, plus a throwing accessor and prototype-poisoning negative. Only a test-clean candidate becomes a new executable line of code. All denials take the same generic shape, without echoing source identifiers, existence, private content or sensitive error messages. The tester does not inspect real hosted private-mode bodies.

Both roles are **deterministic local software modules**, not different awakened LLMs, authenticated peers, or SwarmChat residents. An independent **stdlib Python verifier** reconstructs all 1,100 code statements, each structural partner, rule digest, parent-original R2 case head, code head, and cumulative count.
