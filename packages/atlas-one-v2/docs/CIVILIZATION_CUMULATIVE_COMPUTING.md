# Actual cumulative information processing vs. speculative intelligence

The ONE integrated build is derived from the preexisting exact-source META145 Glyph Memory R14. It **does not** score all 248,832 prior Sphere/node pairs a second time; that score matrix is independently verified as a predecessor input. It adds 144 distinct source/fixture execution receipts and twelve House functional modules on top of that. It retains the original 1,728 House–Sphere *proposed* follow-up records and 1,363 unreviewed lexical candidates.

## Measured local computational gains (independent workload layers)

- **Existing R14 lexical scorer:** 25 paired runs, exhaustive median 267.899 ms vs inverted-postings median 3.831 ms, 69.937× on that isolated 144 × 1,728 score computation (previous local receipt, not a hosted reading).
- **New v3 exact-coordinate retrieval:** 25 paired runs, 1,728 repeated unique-coordinate lookups via array scan vs prebuilt Map. Source digests of returned records matched **exactly**. See output `lookup_benchmark.json` for current machine medians, raw timings and cold Map construction. One-query cold performance may favor a scan; the decision is useful when reused.
- **Existing Noosphere R13 UI:** source-reported Chromium 12.17× median broad-query reset / 19.25× p95 in a previous local browser experiment. This is a *separate* browser rendering layer.

**Never multiply** these ratios or describe them as "intelligence gains." They measure different operations; none proves hosted SwarmChat latency, agent cognition, scientific discovery rate, hardware acoustic behavior or overall application throughput.

## Functional memory

`functional_policy_memory.jsonl` adds one locally verified benchmark event referencing the current original registry source SHA, the existing META145 digest, the new build digest, the exact output parity result and the benchmark file SHA. The hash chain lets a local executor detect tampering. It is **not** an independently trusted host rollback witness: a user with file write access could rewrite both memory and head unless a separately trusted host anchors it. No background or spontaneous learning, model-weight updates, new resident identities, private Palace content, resident activation or paid API call occurred.

The 145th meta-build is the cumulative *software product*, not a sentient 145th actor. Its measured improvements and negative-test evidence are real; other "evolutions" remain proposals until tested.
