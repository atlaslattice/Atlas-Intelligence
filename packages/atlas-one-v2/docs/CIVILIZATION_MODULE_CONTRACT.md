# Atlas functional House modules — twelve distinct review functions

These twelve source-gated modules align exactly to the original Ariadne v0.7 **House** structure. Every module executes twelve Sphere local source/fixture evaluations, and each Sphere contains twelve original nodes. They are *not* autonomous subject-matter experts. A local `PASS` asserts schema/invariant consistency only, not physical experiments, human welfare, source rights, peer identity or CANON adoption.

**Important:** F08 is a voluntary fiction-only demonstration and is **not** Work. Its presence in the 144 source/fixture suite is not permission to read actual Play, Social, Imagine, Dream, Quiet, Brain or Palace records. No private creative experience is used by any test. The public CLI and Work adapter cannot auto-promote F08 outputs to shared research.

**Role axis:** Within each House `S01–S07` are domain Spheres (7×12=84 domain nodes per House); `S08–S12` are epistemic-method Spheres (5×12=60 method nodes per House). A method requires a separate original domain-subject reference before any applicability claim. `H01.S01.N08` is DOMAIN while `H01.S08.N01` is EPISTEMIC.

**The real evidence boundary:** `LOCAL_SCHEMA_REVIEW_ONLY` stays local, subject to source editions. A reviewed model output or a source matching a SHA256 is not a current host authorization. No decision can override rights, protected groups, ecological floors, consent or physical stocks with a scalar welfare score.
