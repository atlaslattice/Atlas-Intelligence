# Atlas 1728 × 144 Civilizational Coverage Adapter (DRAFT)

This source-only public-safe compiler consumes an **operator-supplied private**
NEXT144 manifest and validates Ariadne v0.7 one-based HSN source positions.
It keeps original private source and generated full plans out of GitHub.

- 12 Houses × 12 Spheres × 12 Nodes = 1,728, with 1,008 domain and 720
  epistemic-method roles. Source edition must match the frozen input digest.
- Iterate all 1,728 nodes from each of 144 Sphere perspectives, producing
  248,832 structural/evidence-review row candidates and 12 House follow-ups.
- Produce an exact per-node *proposed* engineering/research work packet for
  Atlas ONE, SwarmChat and Ariadne, plus 1,728 PLANNED macroturn ledger rows.
- Mapping to NEXT1728 `Nmm.ww.oo` software roadmap is a **separate namespace**;
  module suggestions are implementation routing, NOT semantic equivalence.
- No `SAME_AS`, grant, welfare score, CANON adoption, resident assignment,
  independent model turn, science proof, CI, merge or hosted deployment implied.
- No network calls, credentials, room writes, private Play/Brain/Palace intake.

```bash
python3 -m unittest discover -s tests -p test_ariadne_circuit.py -v
python3 scripts/ariadne_circuit.py --source /private/NEXT144_FULL_SOURCE_BOUND_PRIVATE.json --out /private/build
```
